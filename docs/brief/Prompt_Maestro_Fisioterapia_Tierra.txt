PROMPT MAESTRO — FISIOTERAPIA TIERRA

OBJETIVO DEL PROYECTO

Diseña y desarrolla una web completa, funcional y preparada para
producción para FISIOTERAPIA TIERRA, clínica de fisioterapia situada en
Zamora.

La web debe trasladar al entorno digital la identidad visual existente
de Fisioterapia Tierra.

NO debes crear una identidad nueva.

El objetivo es construir una experiencia digital que parezca diseñada
por un estudio profesional de branding, dirección de arte y diseño web,
utilizando el branding existente como punto de partida.

La web debe sentirse: natural · humana · profesional · editorial ·
cálida · sofisticada · contemporánea · tranquila

Debe evitar completamente la estética típica de una clínica médica.

OSTEOPATÍA

FISIOTERAPIA DEPORTIVA

FISIOTERAPIA INVASIVA

“Técnicas que utilizan agujas de punción para acceder de forma precisa a

PUNCIÓN SECA

“Técnica dirigida principalmente al tratamiento del dolor y las
alteraciones musculares, especialmente en presencia de puntos gatillo
miofasciales. Mediante una aguja fina se accede de forma precisa al
tejido muscular, permitiendo actuar sobre zonas profundas que pueden ser
difíciles de abordar mediante técnicas manuales.”

ELECTRÓLISIS PERCUTÁNEA

“Técnica de fisioterapia invasiva que permite aplicar una corriente
galvánica de forma precisa sobre el tejido lesionado, mediante una aguja
y con control ecográfico.

La aplicación de la corriente provoca una respuesta local en el tejido
que puede ayudar a modular el dolor, favorecer la respuesta inflamatoria
necesaria para la reparación y estimular los procesos de recuperación y
regeneración tisular.

Se utiliza principalmente en el tratamiento de lesiones
musculoesqueléticas, especialmente en tendones, músculos y otros tejidos
blandos.”

ECOGRAFÍA

“La ecografía musculoesquelética es una herramienta de valoración que
permite observar en tiempo real diferentes estructuras del aparato
locomotor, como músculos, tendones, ligamentos y otras partes blandas.

Nos ayuda a conocer con mayor precisión el estado de los tejidos,
orientar el diagnóstico fisioterapéutico y adaptar el tratamiento a cada
caso.

Además, permite realizar un seguimiento de la evolución durante el
proceso de recuperación.”

A través de ejercicios basados en los principios del método Pilates,

Un trabajo consciente y progresivo que busca mejorar la relación con tu
cuerpo y la calidad de tus movimientos.”

DIATERMIA

“La diatermia es una técnica que utiliza corrientes de alta frecuencia
para generar un efecto térmico en los tejidos y favorecer determinados
procesos fisiológicos.

En Tierra contamos con Fisiowarm 7.0, que utilizamos como complemento al

tejidos, favorecer la relajación muscular y acompañar los procesos de
recuperación y reparación tisular.

La intensidad y aplicación se adaptan a las necesidades de cada persona

-   versiones cromáticas

Utilizar siempre la versión correcta del logo para cada fondo.

28. REGLA ANTI-IA

Antes de finalizar el diseño, realizar una revisión completa.

Para cada sección preguntar:

¿Podría esta sección pertenecer a cualquier clínica de fisioterapia?

Si la respuesta es sí:

REDISEÑARLA.

Preguntar también:

-   ¿La identidad de Tierra es reconocible sin leer el nombre?
-   ¿Las curvas topográficas están integradas de forma inteligente?
-   ¿Las fotografías parecen formar parte del mismo universo?
-   ¿Existe ritmo entre las secciones?
-   ¿Hay demasiado contenido dentro de tarjetas?
-   ¿Hay demasiados grids?
-   ¿Hay demasiados componentes repetidos?
-   ¿Las animaciones tienen una razón?
-   ¿El diseño aprovecha realmente el branding?
-   ¿Parece diseñado por un estudio o generado mediante una plantilla?

El resultado final debe superar esta revisión.

29. NO COPIAR EL MANUAL

El manual es la fuente de identidad, pero la web NO debe parecer una
copia del manual.

No colocar simplemente las composiciones del manual como fondos.

No reproducir literalmente las páginas del PDF.

Utilizar el sistema visual y crear una experiencia digital nueva.

30. PRIORIDADES

Si existe conflicto entre decisiones, utilizar este orden:

1.  Identidad de marca
2.  Contenido aprobado por la clienta
3.  Legibilidad
4.  Experiencia de usuario
5.  Conversión
6.  Accesibilidad
7.  Rendimiento
8.  Efectos visuales

Los efectos visuales nunca deben tener prioridad sobre la identidad o la
usabilidad.
